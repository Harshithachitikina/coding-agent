Agentic AI Coding Agent

An AI-powered Coding Agent that uses an agentic workflow to understand programming requests and delegate tasks between a Supervisor and a Coding Agent.

Features

Supervisor-based agent orchestration

Coding Agent for writing, explaining, testing, and debugging code

Handles programming requests such as palindrome programs

Uses OpenRouter API

Uses the openrouter/free model for testing

Interactive web interface

Agent Workflow

User Request
     ↓
Supervisor
     ↓
Coding Agent
     ↓
Code / Explanation / Debugging

The Supervisor delegates the task to the Coding Agent, which handles the programming request.

Technologies

Python

Agentic AI

OpenRouter API

Streamlit

Multi-agent orchestration

Example

Write a C program on palindrome

The Supervisor delegates the request to the Coding Agent, which generates the programming response.

Purpose

This project demonstrates basic Agentic AI concepts such as agent orchestration, task delegation, and AI-assisted coding.
